Perguntas Frequentes

Quais dados são disponibilizados no URBIS?
keyboard_arrow_up

Dadas suas finalidades específicas de melhorar a competitividade empresarial, com foco nas pequenas empresas, por meio sobretudo da redução de assimetrias de acesso à informação e da sua compreensão de maneira fácil, clara e padronizada, o Urbis possui uma curadoria de dados cujo elemento comum é a utilidade ao desenvolvimento de atividades econômicas urbanas (parcelar, construir, usar). Nele é possível encontrar, por exemplo, dados nas temáticas:

  • Civil (ex.: faixas de domínio, faixas não edificáveis, servidões administrativas)
  • Urbanística (ex.: macrozoneamento, zoneamento, planos específicos, leis especiais)
  • Ambiental (ex.: Áreas de Preservação Permanente, Unidades de Conservação, Áreas de Preservação e Recuperação dos Mananciais)
  • Cultural (ex.: tombamentos, áreas envoltórias, tombamentos ambientais e paisagísticos)

Os dados são disponibilizados em formatos abertos de mercado, como o GeoJSON, permitindo seu uso em análises por acadêmicos, gestores e público em geral, assim como para o desenvolvimento de aplicações.

Como funciona o processo de atualização dos dados?
keyboard_arrow_up

Para garantir a atualidade e a integridade do dado, utilizamos a arquitetura de medalhões. Os dados passam por camadas de validação e transformação — desde a ingestão bruta até ao tratamento final.

Todo este fluxo de coleta, transformação e publicação é orquestrado pelo Dagster, o que nos permite manter o catálogo sempre atualizado de forma eficiente.

O código de orquestração do projeto fica disponível no repositório: Urbis DataLake no GitHub.

Quais são as formas de consumo dos dados?
keyboard_arrow_up

O Urbis foi desenhado para atender a diferentes perfis de utilizadores. Existem três formas de acesso aos dados:

  • Interface Web: tanto pelo Mapa.Urbis quanto pelo DadosAbertos.Urbis, é possível ao usuário comum navegar pesquisando, filtrando e visualizando dados do nosso data lake. No DadosAbertos.Urbis, em específico, é possível filtrar por grupos e etiquetas, pré-visualizar tabelas ou mapas diretamente no navegador, e fazer o download em formatos abertos, como o GeoJSON
  • Geoserver: através de autenticação na API Urbis, desenvolvedores e analistas de dados geográficos podem acessar os serviços de Web Map Service (WMS) e Web Feature Service (WFS) — mais informações em Docs.Urbis, Consumo Externo de Mapas (WMS / WFS)
  • API CKAN: através da API do CKAN, desenvolvedores e cientistas de dados podem acessar de forma automatizada e em tempo real os dados e metadados do Urbis — mais informações em Docs.CKAN, API guide
Como utilizar a API do portal URBIS?
keyboard_arrow_up

O portal URBIS expõe publicamente a API do CKAN, que permite consultar o catálogo de forma programática. Com ela, é possível:

  • Consultar todos os metadados do portal
  • Baixar todos os arquivos do portal
