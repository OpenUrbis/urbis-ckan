URBIS - Dados Abertos

{% if intro %} {{ h.render_markdown(intro) }} {% else %}

O Urbis é uma solução desenvolvida pela Prefeitura de São Paulo para a finalidade específica de integrar e apresentar dados de forma útil às atividades econômicas urbanas (parcelar, construir, usar), com foco nos pequenos empresários. Ele é um software livre de licenças públicas com cláusula copyleft e foi construído com tecnologias atuais e uma infraestrutura robusta, disponibilizando nos seus vários componentes poderosas ferramentas de alimentação, gestão, apresentação, manipulação e extração de dados, com capacidade de geração de documentos. Este componente, o DadosAbertos.Urbis, é voltado à publicação de metadados dos dados do Mapa.Urbis, que incluem (1) os estudos sobre o dado; (2) descrição semântica do dado; (3) descrição técnica do dado (fonte, transformações e formato); (4) opções de consumo (geoserver, download e API CKAN); (5) classificação do dado na organização do Urbis (permitindo ver outros dados semelhantes).
